# Meeting Prep Agent

AI-powered Meeting Prep Agent that helps users prepare for meetings by managing contacts, creating meeting notes, generating AI-powered summaries, and organizing meeting information.

## Features

- User Authentication (Login / Signup)
- User Profile Management
- Contact Management
- Meeting Notes Management
- AI Summary Generation using Groq
- Meeting Brief Preparation
- Secure Logout & Route Protection

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Groq SDK
