# Frontend - Meeting Prep Agent

## Overview

The frontend of the Meeting Prep Agent provides the user interface for:

- User Authentication
- Profile Management
- Contact Management
- Meeting Notes
- AI Summary Generation
- Meeting Brief Viewing

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Main Pages

### login.html
User login page.

### signup.html
User registration page.

### index.html
Application home page.

### profile.html
User profile creation and management.

### contacts.html
Contact management page.

### meeting.html
Meeting notes and AI summary generation page.

### brief.html
Meeting brief viewing page.

## Running Frontend

Open the frontend folder using Live Server.

Example:

http://127.0.0.1:5500/frontend/login.html

## Features

- User Authentication
- Session Management
- Protected Routes
- Logout Functionality
- Profile Ownership Isolation
- Contact Management
- Meeting Notes Workflow
- AI Summary Generation
